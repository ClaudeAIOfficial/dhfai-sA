# The News Bureau
A responsive editorial news website concept, inspired by modern newsroom homepages.

## Run locally
Open `index.html` in your browser, or use `python -m http.server 8000` from this folder and open http://localhost:8000. Clean article URLs work through history routing on hosts that support SPA rewrites; `vercel.json` includes rewrites for Vercel.

## Included
- Homepage with hero story, sidebar, editor picks, latest list, trending module and advertising placeholder
- World, Politics, Business, Technology, Science, Lifestyle, Media and Travel category navigation
- Article pages, search, dark mode, bookmarking, share controls, responsive layout
- Original TNB logo and banner
- Demo newsletter that stores a value only in localStorage (not sent or collected)

## Before publication
All editorial articles are samples and MUST be replaced with verified news. The current photos are illustrative third-party images fetched at runtime from Unsplash. Obtain proper licenses, confirm attribution, and consider self-hosting. Set a real contact email, privacy/legal pages, analytics, CMS and newsletter backend. Politics category is empty pending articles.
